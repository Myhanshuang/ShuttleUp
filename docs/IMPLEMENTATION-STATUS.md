# ShuttleUp 实施状态

更新时间：2026-09-11

本文件只记录实际实现和已运行验证。外部真实联调不会以 fixture、人工来源或演示数据替代。

## 本次入口与交互重构

- Vue 页面已替换为 React + React Router；默认活动工作台读取真实参与列表；统一侧栏进入活动、时间、账单、设置。
- 登录/注册为主入口，游客需主动选择；邀请流程保留登录后的目标页面。
- 活动按收集时间、订场确认、到场、核对结算展示当前操作；成员空闲汇总随活动刷新。
- 时间页提供周视图、拖选/点选、分钟级表单、混合时段颜色、待保存预览、撤销、标签页草稿、每周重复和个人/活动范围。保存采用修订校验；重叠笔画按最后一次编辑生效。
- AstrBot 是公共交互入口，首次发起无需网页账号；自动识别发送者并关联会话。业务操作复用网页处理，一条命令与幂等结果在同一事务提交；私聊一次性链接进入同一网页身份。
- 已验证 React 类型检查和生产构建、Python 29 个测试、Vitest 1 个测试、Chromium 桌面与手机共 4 个端到端用例。真实平台联调仍待配置。
