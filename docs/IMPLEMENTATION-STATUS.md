## M7 验收与部署

- 状态：部署包完成；真实外部联调和扩展浏览器验收待项目输入。
- 测试：Python `19 passed`；Vitest `1 passed`；Playwright 在 Chromium 中以 `390×844` 和 `1280×800` 两个项目各通过一次真实 API 创建流程；npm audit `0 vulnerabilities`。
- 构建：活动页所需全部 JS gzip 约 47.46KB（预算 180KB），全部 CSS gzip 约 3.20KB（预算 30KB）。测量脚本进程峰值 RSS 18.27MB；这不是完整 E2E 容器 RSS。
- 镜像：`docker build -t shuttleup:local-test .` 成功；镜像内实际 SQLite `3.51.3`，应用加载 81 条路由。
- 部署：`Dockerfile`、`compose.yaml`、迁移前启动、非 root 用户、健康检查、512MB 限制、Nginx SSE 配置、备份恢复说明均已交付。

## 尚需使用方提供的验收输入

1. 首个目标场馆网站地址、允许的访问方式和必要授权。
2. 联调时仍有效的 WakeUp 分享口令。
3. 实际 AstrBot 部署地址、版本和消息平台配置。

这三项不阻碍当前镜像部署和人工/标准 JSON 场地源使用，但在完成前，PRD A13 的双浏览器时延实测、A29 的真实主动消息和 A32 的两项真实来源联调不会标记为完成。
