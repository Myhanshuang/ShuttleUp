# ShuttleUp 视觉设计

受众是一起约球的球友。主任务是安排时间、选场、确认到场和结算，不做营销网站。

## 设计方案

- 色彩：球场蓝 #245BD7，深蓝墨色 #182C49，冷灰底 #F3F6FB，白色 #FFFFFF，薄荷绿 #C9EADF，记分牌黄 #F3D47A。
- 字体：中文优先 Source Han Sans CN / Noto Sans CJK SC；英文使用 Avenir Next。时间、金额使用 tabular-nums。标题 30–36、区块 19–22、正文 14–15、辅助信息 12–13 px。
- 布局：侧栏统一导航，内容左对齐；活动列表强调日期、名称、阶段、下一步；时间表占据主操作区。

方案 A：大幅宣传区 + 统计卡片 + 活动卡片网格。
方案 B（采用）：紧凑球场图形 + 活动清单 + 明确的阶段操作。

```text
桌面
┌ 导航 ┬ 标题                         发起约球 ┐
│      │ 约时间的说明           羽毛球场图形   │
│      ├ 我的活动                     筛选   ┤
│      │ 日期   活动名称/时间   阶段/下一步   │
│ 账号 │ 日期   活动名称/时间   阶段/下一步   │
└──────┴───────────────────────────────────┘
手机
┌ 品牌                              导航 ┐
│ 页面标题                          操作 │
│ 说明 / 球场图形                        │
│ 活动日期、名称                         │
│ 阶段与下一步                           │
└────────────────────────────────────────┘
```

## 方案复核

移除方案 A 的大数字、重复口号和等尺寸卡片网格：它们与约球决策无关，容易成为通用后台模板。把辨识度集中在蓝色羽毛球场图形，其他界面保持安静。保留实际流程中的步骤编号，不添加装饰编号。无渐变和自动动画。

时间语义继续区分：未设置为浅灰，空闲为薄荷绿，忙碌为淡红，不确定为紫蓝；选中使用高对比边框，未保存保留斜纹。

## 第二轮：完成约球的操作层级

沿用上述六色、字体和左对齐规则。辨识度仍集中在球场图形；登录后的首页减少介绍区，让需要本人处理的活动优先。不要新增装饰性统计卡片。

比较：把所有表单铺开会挤占活动主线；采用「阶段摘要 → 本人下一步 → 方案 / 名单」，设置点击后展开。取消独立显示中止状态，结清才显示流程全部完成。

```text
活动：活动与实际时间 → 流程 → 本人的下一步
      方案（人员 / 场地 / 价格） │ 安排摘要 / 按需编辑
      调整时长 → 预览 → 采用     │ 最近变更
手机时间：活动上下文 / 流程 → 日期切换 → 单日时间格
          点选编辑 / 来源说明 / 待保存列表
          固定操作栏：待保存数量 / 撤销 / 保存并返回
```

方案预览保持人员、场馆等条件不变，仅变更明确选择的时长；确认前列出实际名单。颜色以统一变量表达状态，继承来源另用文字与边线，不增加一套状态色。反馈固定在视口内且可关闭，长页面底部也能看到。邮箱找回复用邮箱行与验证码布局。
