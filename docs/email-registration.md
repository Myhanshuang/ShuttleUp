# 邮箱注册与发件配置

系统支持「邮箱 + 验证码 + 密码」注册，之后用邮箱和密码登录。游客注册会保留原身份、活动和空闲时间。用户名注册已关闭，新账号必须验证邮箱；已有账号仍可使用用户名登录。支持通过注册邮箱找回密码；暂不提供更换邮箱。

## 用 QQ 邮箱发信

1. 登录 QQ 邮箱网页版，在设置中找到 POP3/IMAP/SMTP 服务（入口也可能位于「账号与安全」）。
2. 开启 POP3/SMTP 或 IMAP/SMTP，按提示验证身份并生成授权码。
3. 在项目根目录本机 `.env` 中追加以下配置，不要覆盖文件里已有设置：

```dotenv
SMTP_HOST=smtp.qq.com
SMTP_PORT=465
SMTP_SECURITY=ssl
SMTP_USERNAME=你的QQ邮箱@qq.com
SMTP_FROM=你的QQ邮箱@qq.com
SMTP_PASSWORD=生成的授权码
```

授权码不是邮箱登录密码，不要发到聊天或提交到 Git。`.env` 已被 Git 忽略。
参考：[腾讯 SMTP 配置说明](https://main.qcloudimg.com/raw/document/product/pdf/1270_46586_cn.pdf)。

4. 重启后端使配置生效。在「登录 / 注册 → 注册 → 邮箱注册」填写收件邮箱并发送验证码。收件邮箱不必与发件邮箱相同，也可以是 Gmail、Outlook 等邮箱。

发送失败时检查 SMTP 是否开启、授权码是否有效、服务器能否连接 SMTP 端口，以及邮件是否进入垃圾箱。系统不会将验证码、授权码或 SMTP 异常详情返回给浏览器。

其他发信服务可修改主机、端口和凭据，支持 `ssl`（通常 465）及 `starttls`（通常 587）；当前 SMTP 客户端支持密码/应用授权码认证，不支持 OAuth2。

## 接口与限制

- `GET /api/v1/auth/options`：是否配置邮件发送服务。
- `POST /api/v1/auth/email/code`：邮箱地址，返回 challenge_id；验证码仅通过邮件发送。
- `POST /api/v1/auth/email/register`：email、challenge_id、code、password、display_name。
- `POST /api/v1/auth/login`：username 字段也接受邮箱地址。

验证码 10 分钟有效、一次性使用；输错 5 次失效；同邮箱重发间隔 60 秒，每小时最多尝试发送 5 次，每 IP 每小时 20 次。失败投递也计入发送限额。验证码以 HMAC 保存。已登录游客须携带 CSRF，并使用为自身身份获取的验证码。

配置缺失时页面提示未配置并禁用发送；自动化测试使用模拟 SMTP，不向真实邮箱发信。现有本地启动流程会自动创建新增表；使用 Alembic 管理的部署运行 `alembic -c backend/alembic.ini upgrade head`。

## 游客身份保留

游客创建时会显示一次高强度随机恢复码；已有游客可在个人设置中生成。恢复码仅在数据库中保存哈希，前端只临时显示，不写入浏览器存储。请手动复制保存；关闭提示或刷新后无法重新查看，只能生成新码。

登录页选择「用恢复码找回游客身份」可恢复同一个用户 ID，原活动、空闲时间和账单仍然关联该身份。恢复成功后旧码失效、旧设备会话撤销，并显示新恢复码。重新生成码也会使旧码失效。绑定邮箱后游客恢复码失效，应使用邮箱登录。

游客会话有效期为 30 天。加载会话时若距离上次续期超过一天，服务器与浏览器 Cookie 同步续至 30 天；页面持续打开时每小时检查会话。已过期会话不会自动恢复，须使用恢复码或已绑定账号登录。

## 指定系统管理员

部署者可以在本机 `.env` 配置 `BOOTSTRAP_ADMIN_EMAIL=owner@example.com`。该邮箱通过验证码完成注册或游客升级时，会获得系统管理员权限；其他邮箱仍是普通账号。浏览器不能修改这个配置，也不能通过提交 `is_admin` 字段获得权限。配置变更需要重启后端。

已注册的账号不会因修改此配置被追溯提权，需由部署者核对账号后设置角色。现有账号的权限也不会因清空配置而自动撤销。

管理员登录后，侧栏显示「场馆管理」：可添加已接入来源下的场馆、编辑名称/地址/预约链接/参考价格、停用或重新启用，并维护来源登录。停用保留历史数据。新增查询来源仍通过部署配置或来源扩展完成；添加场馆资料不会自动取得场地余量。
## 邮箱密码找回

登录页的「忘记密码？」使用现有 SMTP 配置，不需要增加参数。输入注册邮箱、验证码和两次新密码后完成重设，原身份和活动保留，所有设备的 Web 登录失效，需重新登录。

找回验证码与注册验证码分别存储，不能混用；有效期 10 分钟，最多尝试 5 次，60 秒重发间隔，并与注册共用邮箱 / IP 发送限额。未注册或停用邮箱得到相同的受理提示。恢复码仍用于游客；未绑定邮箱的旧用户名账号需要管理员协助。

数据库新增 `password_reset_challenges` 表。应用自建表启动方式会自动创建；使用 Alembic 的部署应应用迁移 `ca62f119a430`。
