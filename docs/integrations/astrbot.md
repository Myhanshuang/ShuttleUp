# AstrBot 公共交互入口

AstrBot 和 React Web 是同一服务的两个入口。Bot 不属于某个用户，也不要求先在网页注册。服务通过插件透传的平台实例 ID 和发送者 ID 识别用户，首次操作自动创建身份。群里的创建者是主持人，其他发消息的人是各自的成员，权限不会共享。

## QQ 身份绑定

群里 `@Bot /绑定身份 小林`，或 `/羽球 绑定身份 小林`，即可为当前发消息的 QQ 创建并绑定 ShuttleUp 身份。省略昵称时使用 QQ 昵称；不接受代填其他 QQ 号码。重复执行返回已有身份，不会重复开户或覆盖现有身份。之后私聊 `/羽球 网页` 登录同一身份，在个人设置升级为用户名密码账号。

## 群内流程

1. `@Bot /发起约球 周末夜场`：直接创建活动并关联当前群。
2. `/羽球 加入`：获取群当前活动的邀请页，填写本次空闲时间后加入。
3. `/羽球 有空 2026-09-19 18:00-20:00`：填写仅本次活动的时间；加 `--个人` 写入个人时间。
4. `/羽球 推荐`、`/羽球 选择 1`：查看并选择当前推荐，选择时重新检查可行性。
5. `/羽球 参加`：确认参加；主持人实际预约后 `/羽球 已订 1号场 订单号`。
6. `/羽球 到场`、`/羽球 记账 球费 48`：记录到场和实际支出。
7. `/羽球 结束`：主持人结束活动，然后在网页核对各成员到场。`/羽球 结算` 发布账单。
8. 私聊 `/羽球 账单 --活动 短号` 查看自己的付款任务；`/羽球 已付 任务短号 --活动 短号` 声明付款，收款人 `/羽球 收款 声明短号 --活动 短号` 确认。

多场活动用 `/羽球 活动` 查看、`/羽球 切换 短号` 切换，或为指令增加 `--活动 短号`。群内仅允许操作已关联到本群的活动。

## Web 中继续

私聊 `/羽球 网页` 获得 10 分钟有效的一次性链接。在网页明确确认后登录相同身份，活动、时间和费用都会保留。链接放在 URL fragment 中，通过 POST 兑换，不会因普通 GET 预览而消耗。不要转发链接。

已有网页账号可以在首次使用 Bot 前生成绑定码，私聊 `/羽球 绑定 绑定码`。这是可选的身份关联；暂不支持合并两个已有身份，避免丢失成员和账款关系。网页创建的活动仍可通过主持人的群关联码接入群聊。

## 实现与验证

`integrations/helper.py` 将消息转换为与网页相同的业务请求，复用创建、加入、时间、参加、订单和账务处理，整条命令与幂等结果在同一事务提交。内部 helper 身份由已校验服务令牌的适配器构造，HTTP 请求不能通过字段或头部构造该身份。

自动测试覆盖首次创建、重复 message_id、多人加入、跨群隔离、主持人权限、输入校验、账单冻结和一次性网页登录。真实平台联调仍需部署 URL、AstrBot 版本及消息平台配置。

插件事件接口参照 [AstrBot 官方事件文档](https://docs.astrbot.app/dev/star/guides/listen-message-event.html) 与 [官方过滤器接口](https://github.com/AstrBotDevs/AstrBot/blob/master/astrbot/api/event/filter/__init__.py)。
