# WakeUp 分享导入

默认直接使用 WakeUp 分享协议：服务端请求会话签名，再读取并解密 `share_schedule/getv2`，无需另外配置适配服务。网络层使用固定 HTTPS 主机，不跟随重定向，不记录口令、请求正文或上游原始错误。

## 使用

在「我的时间 → 从 WakeUp 导入课表」粘贴完整分享文案或 32 位口令，点击预览。确认课程数、学期日期与繁忙时段明细后，再确认导入。分享失效时需在 WakeUp 重新分享；预览有效期 10 分钟。确认前不修改个人时间。

同名课表重新导入会替换原导入的课程规则，保留其他个人时间；删除导入会移除对应课程规则。课程名称仅用于内存预览，数据库只保留课表名称、时间区间和导入元数据，不保留口令、教师、教室或原始课表。

## 转换和限制

解析五段课表数据：时间表定义、节次时间、学期设置、课程定义、上课安排。支持单周、双周、分段周次、连续节次和自定义时间；逐节展开，保留课间。当前使用 Asia/Shanghai。不支持跨午夜节次，时间倒置、缺失节次、未知周次类型会拒绝整份导入，避免静默漏课或猜测时间。

公开客户端协议兼容实现引用 WakeUpDecoder，Apache-2.0，许可证和修改说明见 backend/shuttleup/availability/WAKEUP-LICENSE 与 WAKEUP-NOTICE.md。只包含协议函数与公开应用常量，不附带 APK。

`WAKEUP_SHARE_ENDPOINT` 留空即可使用内置协议；仍可设置为已有的标准化适配服务地址，但不能直接填官方 getv2 地址。上游私有协议发生变化时可能需要更新客户端实现。
